02

確認標準內容

請核對正確資料，確認每個字

照片辨識及系統資料僅供填入參考，核准後才會成為比對標準。

規格、保存條件、公司名稱、電話填寫後會逐字核對；未填的項目不檢查。沒有「地址：」前綴也可辨識，仍請核對是否完整。

例如 11/10 製造、11/13 到期，日期相差 3 天。照片日期只用於確認標準，不會拿來核對以後每一批。

啟用後檢查到店日格式；每批的正確日期請在「檢查標籤」填入「本批到店日」，不會沿用這張標準照片的日期。
